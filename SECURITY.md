# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting: on this repository open
**Security > Advisories > Report a vulnerability**
(https://github.com/spinelminer/spinelminer/security/advisories/new). Only the maintainers can see
the report.

Include the miner version (`spinelminer --version`), your OS and what you observed, and how to
reproduce it. Do not include wallet keys, passwords or pool credentials.

## Scope

Only the released binaries are in scope: this repository contains no source code. Downloads should be
verified against `SHA256SUMS` from the same release.
