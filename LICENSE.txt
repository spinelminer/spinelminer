6. Network connections and data
   The Software connects only to:
   - the pools or solo gateway you configure;
   - the developer's dev-fee pools;
   - those pools' hosts, for a short connection-time probe used to choose the fastest dev-fee
     region;
   - a proxy, if you configure one;
   - only if you enable it with --telemetry, the Licensor's kernel-report service (below).
   It sends pools the wallet and worker name you configure, and the shares it finds (a pool
   password given with -p is not sent). The optional local stats API (`--api-port`) binds to
   127.0.0.1 unless you choose another address.

   Telemetry is off by default. Without --telemetry (config key "telemetry") the Software sends
   no telemetry, usage statistics or personal data to the Licensor and opens no connection to the
   kernel-report service. With it, the Software sends anonymous kernel reports to that service
   (through your proxy, if you configure one): 10 minutes after start, one report per GPU
   architecture and kernel build that the service still asks for (at most once per install per
   GPU architecture, miner version and kernel build), and at once when a GPU has no working
   kernel (at most once per install per GPU architecture, mining kernel variant and miner
   version). A report covers at most 16 GPUs. A report holds only:
   - the report format version, the miner version, the kernel build hash, the operating system
     and CPU architecture, and, when known, the HIP runtime and driver versions;
   - per GPU: the architecture (gfx), the model name, compute-unit count, PCI device id and memory
     size; the mining kernel chosen and whether it is validated; the kernels that failed the
     startup self-test before it, each with a failure code (and the failing lane, HIP error name,
     signal or exit number); the self-test result and duration; the auto-tune state, the work
     shapes measured with their speed, and the shape used; and a speed summary (TH/s, slice-time
     p50/p95/max, local rejects, watchdog events, temperature pauses, highest junction
     temperature);
   - a random install ID created on first use and stored in the miner's cache directory (sent as
     a request header, used only to limit and de-duplicate reports).
   A report never contains a wallet, pool address, user or worker name, password, host name, IP
   address, file path, command line or error message text. The service necessarily sees the
   connecting IP address; it uses it only for rate limiting and never stores it.
